Gauchar Mela 2026 - redesign
How to run in VS Code:
1. File > Open Folder > select the gauchar-mela folder.
2. Install the 'Live Server' extension, right-click index.html > Open with Live Server.
   (Or just double-click index.html to open it in the browser.)
Files: index.html, css/style.css, js/script.js, images/ (put your photos here).
Banner photos: edit the IMG list near the top of the slider code in js/script.js.
Pages are in js/script.js (the P object). Events/notices/rates: fill in the docs and days there.

Banner photos: save 4 photos as images/slide1.jpg, slide2.jpg, slide3.jpg, slide4.jpg (any size, wide photos look best).
